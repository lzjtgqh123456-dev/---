# 课表 Excel 解析规则（依据用户提供的真实样例）

## 源文件
`D:\ai\课表样式.xlsx`（俄罗斯大学 ВШРФК 专业课表）
- 3 个工作表：`ВШРФК`（主表，91 行 × 1569 列）、`ВШРФК (Статистика).`、`ДН`
- 主表形态：**按教室排的矩阵**，列 = 教室，行 = 星期 × 时间
- 表头分布：
  - r3 `Оснащение` 设备
  - r4 `Кол. мест` 座位数
  - r5 `Описание` 教室描述（如 `216 (25) РЛиМП`）← **列 → 教室号的来源**
  - r6 `День | Время | <教室号…>`
  - r7 `Нед` 该行后续数字 = 可用周次
  - r8+ 星期（`понедельник` …）+ 时间（Excel 小数）+ 各教室的课程文字
- 时间需换算：Excel 小数 × 24h，如 `0.354166` → 08:30

## 单元格内容格式（关键）

```
10.3-256 ДВ Методы и принципы соврменной лингвистики (русский язык) (Пр. 2-11, 16-17 нед., 24 ч.), Усманова Л.А.
//
10.3-622Б Практическая грамматика Пр., Спиридонов А.В. (12-13,15 нед., 6 ч.)
```

### 字段解析
| 字段 | 位置/规则 | 样例 |
|---|---|---|
| **班级** | 开头 `10.3-<编号>`，编号后可能带 `а`/`б` 表示分组 | `256`、`622Б` |
| **课程名** | 班级之后、类型标记之前的部分 | `ДВ Методы и принципы соврменной лингвистики (русский язык)` |
| **类型** | 缩写标记 | `Пр.` = практическое занятие（实践课/研讨）|
| **周次** | 括号内 `X-Y, Z нед.` | `2-11, 16-17`、`12-13,15` |
| **学时** | 括号内 `N ч.` | `24 ч.`、`6 ч.` |
| **教师** | 条目末尾（姓氏 + 缩写） | `Усманова Л.А.`、`Спиридонов А.В.` |
| **多条目** | 同一单元格用 `//` 分隔多门课 | 上例含 2 门课 |

### 类型缩写对照（需补全）
| 缩写 | 俄文全称 | 中文 |
|---|---|---|
| `Пр.` | практическое занятие | 实践课/研讨 |
| `Лек.` / `Л.` | лекция | 讲授课 |
| `Сем.` | семинар | 研讨课 |
| `Лаб.` | лабораторная | 实验课 |
| `ДВ` | дисциплина по выбору | 选修课（作为课程名前缀出现）|
| `ФТД` | факультатив | 选修 |

## 映射到 App 数据模型
```
专业 = sheet 名（ВШРФК）
 └ 班级 = 10.3-<编号>（如 354、622Б）      ← 进「班级分类列表」，可按其筛选课表
    └ 课程 = 课程名（含 ДВ 等前缀）
       ├ 类型 → ClassType（Пр.→SEMINAR/LAB 视情况，Лек.→LECTURE）
       ├ 教师 → teacher
       ├ 上课时段 = 星期 + 时间（由所在行决定）
       ├ 教室 → location（由所在列决定）
       └ 周次 → weekFrom/weekTo + parity（如 2-11、16-17 为多段，需拆成多个时段或取并集）
```

## 待处理的技术点
1. **合并单元格**：1569 列中大量是横向合并（一个教室占多列），必须先读 `xl/worksheets/sheet1.xml.rels`
   与 `<mergeCells>`，否则教室列错位
2. **多段周次**：`2-11, 16-17` 是两段不连续区间；App 的 CourseSchedule 只有 `weekFrom/weekTo` 单段，
   需要**拆成多条 schedule**（同一门课多段周次）或扩展模型支持多段
3. **分组（а/б）**：同班会分成两组分别上课，应作为不同的「班级」值（如 `256а` / `256б`）
4. **异常格式容错**：真实数据里会有缺失学时、多个教师、跨教室等情况，解析需宽松并记录未解析项
5. **导出**：按此格式反向生成 Excel（列=教室、行=星期×时间），供交教务使用
