# 换 App 图标（自己改）

## 三步
1. 把你的图片放进 **`icon_src/icon.png`**（覆盖掉现在那张学士帽）。
   - 正方形 PNG，**建议 1024×1024**，至少 512×512。
   - 想要"图标只占中间、背景是纯色"：图用**透明背景**（logo 模式）；
     想要"整张图铺满图标"：图**不透明**铺满整张（整图模式）。
2. 跑一句命令重新生成全套图标：
   ```bash
   cd /d/ai/projects/study-assistant
   tools/ocrenv/Scripts/python.exe tools/make_icon.py
   ```
   （想临时用别的文件：`tools/ocrenv/Scripts/python.exe tools/make_icon.py 我的图.png`）
3. 重新打包（生成的文件在 `app/src/main/res/` 里）：
   ```bash
   py "D:\ai\留学助手\android-toolchain\build.py" "D:\ai\projects\study-assistant" :app:assembleDebug
   ```

## 背景色（logo 模式）
默认用 App 主题青 `#14625A`。想换：新建 **`icon_src/bg.txt`**，里面只写一个颜色，例如：
```
#1E6F5C
```

## 脚本到底生成了什么
| 输出 | 用途 |
|---|---|
| `res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` | 传统方形图标（48/72/96/144/192 px） |
| 同上 `ic_launcher_round.png` | 传统圆形图标（画了圆形遮罩） |
| `res/drawable/ic_launcher_foreground.png` | 自适应图标**前景**（432×432，logo 居中缩到 62%，留出安全区） |
| `res/drawable/ic_launcher_background.png` | 自适应图标**背景**（纯色，或整图铺满） |
| `res/mipmap-anydpi-v26/ic_launcher.xml` `ic_launcher_round.xml` | 自适应图标定义（含 Android 13+ 的 monochrome 主题图标） |

> App 的 minSdk 是 26，所以**自适应图标就够用**；传统 PNG 也一起生成了，个别老启动器/桌面主题会用上。

## 想改形状 / 留白比例
`tools/make_icon.py` 顶部两个常量：
```python
ADAPTIVE = 432     # 自适应图层边长
LOGO_SCALE = 0.62  # logo 占画布比例（调大=图标更大，但太大会被圆形/方形遮罩切到）
```
