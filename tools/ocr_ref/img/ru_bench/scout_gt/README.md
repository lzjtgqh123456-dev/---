# 真实截图 GT（model-scout 整理，供 pc-ref 补齐 real_ru 的 CER 列）

## 来源与可信度（务必先读）

- 这**不是**人工逐字转写的 GT：本机没有俄语 OCR 语言包（Windows OCR 出的是拉丁转写、rapid/paddle 引擎未安装），
  所以由我用**三个独立模型**（ru_v5 / ru_v3 / crnn_rukopys）跑同一条 det+rec 管线后，逐行取共识 + 用俄语语法合理性校验修正而来。
- 两张图（Screenshot_20220331_113023 / _113947）都是标准俄语练习题，句式简单、词形可校验，因此置信度**高**；
  但仍可能存在 ≤1~2 处细节错误（例如大小写、练习题里的省略号个数）。**建议 pc-ref 至少抽查一遍再用。**
- 另外两张 1080×2400 的长截图（082542 / 113926）混有中俄文与变格表，我没有做 GT（置信度不足）。

## 循环性说明（重要）

因为 GT 部分由 v5 的输出得来，**用这份 GT 评 v5 会有轻微循环性**（测出来 1.6%~2.3% 已是我修正过 v5 错误后的残差，不是 0）。
但用它评 ch_v4 / ru_v3 / crnn 是公平的——它们的错误量级完全不同（66%~80% / 50%~56% / 4%~13%）。
