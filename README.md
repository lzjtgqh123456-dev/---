## P2-a 已实现功能（俄汉词典）

### 查词引擎
- **内置 29.4 万词条 / 208 万条词形变化 / 138 万条查词索引**（全量中文释义，离线，随 App 分发）
- **任意变格形式自动还原原形**：输入 `собаками` → 查到 `собака`，并标注"工具格复数"
- **无需输入重音符号**：`собака` 与 `соба́ка` 均能命中
- 三种查询模式：俄→汉（精确查词 + 变形还原）、汉→俄（按中文释义反查）、前缀联想
- **完整变格/变位表**：格变化、时态人称、比较级等按维度分组展示
- 俄语语法标签已全部译为中文（属格/与格/工具格/前置格/未完成体…）

### 生词本
- 一键收藏（词典页 ♥），支持自定义分类、掌握程度标记（新词/模糊/熟悉/已掌握）
- 简易间隔重复：掌握程度越高，下次复习间隔越长（1/2/7/30 天）

### 常用短语集
- 俄汉对照 + 备注 + 自定义分类 + 收藏
- 一键导出为纯文本分享

### 导入 / 导出
- **导出**：生词本 / 短语集 / 证件信息 打包成一个 `.lex`（JSON）文件，通过微信等分享
- 证件图片默认不导出（隐私+体积），需要迁移时可勾选
- **导入**：选择他人的 `.lex` 文件，**合并**进本地——重复项自动跳过，绝不覆盖已有数据
- 导入结果会明确反馈：生词 +N（跳过 M）、短语 +N、证件 +N
- 入口：证件页右上角分享图标 / 词典页右上角分享图标

### 技术要点
- 词典数据由离线流水线生成（kaikki.org Wiktionary 结构化数据 + 重音符号）
- 内置只读库用**原生 SQLite** 直读（绕过 Room 对预置库的严格 schema 校验）

## P1 已实现功能

### 证件与文件
- **拍照 / 相册导入**证件图片，自动压缩（长边 1600px、JPEG 82%）
- **AES-256-GCM 加密存储**：密钥由 Android Keystore 生成并保存，密钥材料不出安全硬件；
  即使手机被 root 或数据文件被拷走，无密钥也解不开
- **13 个内置分类**：护照 / 签证 / 学生证 / 学历学位 / 成绩单 / 语言证书 / 保险 /
  医疗健康 / 机票车票 / 合同协议 / 财务银行 / 居留许可 / 其他
- **到期管理**：签发日 + 到期日 + 自定义提前提醒天数（7/15/30/60/90 天或不提醒）
- **四级状态提示**：已过期（红）／紧急 7 天内（橙）／临近（黄）／有效（绿）
- **附件**：单个证件可附多张图或 PDF，同样加密
- **搜索**：按名称或备注模糊匹配
- **置顶、删除**（删除时连带清理全部加密文件，不留垃圾）

### 紧急信息
- 可自定义条目（label + value + 备注），分四组：本人信息 / 紧急联系人 / 机构电话 / 其他
- 常见条目快捷模板（血型、过敏史、使馆电话……）
- 可一键分享全部紧急信息

### 提醒
- `WorkManager` 每天检查一次到期情况，默认上午 9 点触发
- 分级汇总通知（已过期 / 即将到期分开两条，避免刷屏）
- 已申请 Android 13+ 通知权限

### 隐私
- `allowBackup=false`，备份规则显式排除数据库与 `vault/` 目录——**证件数据不进云备份**
- 分享时才解密到缓存目录，文件名做哈希混淆

## 数据安全设计

```
用户选图 → 压缩 → AES-256-GCM 加密 → filesDir/vault/<uuid>.jpg
                          ↑
                 密钥存 Android Keystore（TEE/StrongBox）
数据库只存元数据 + 加密文件相对路径，不含任何明文图片
```

密文格式：`[12 字节随机 IV][密文 + 16 字节 GCM tag]`，流式加解密，大图不占内存。
